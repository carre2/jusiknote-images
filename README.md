# jusiknote-images

[jusiknote.com](https://www.jusiknote.com) 블로그에 쓰는 이미지 저장소입니다.
[jsDelivr](https://www.jsdelivr.com/) CDN을 통해 서빙됩니다.

```
https://cdn.jsdelivr.net/gh/carre2/jusiknote-images@main/img/<파일명>
```

- `img/` — 썸네일(`IMG_T34.png`)과 본문 이미지(`IMG_341.jpg`)
- 파일은 **덮어쓰지 않고 추가만** 합니다 (CDN 캐시 때문)
